# 基于 pthread 的多生产者多消费者任务队列系统

## 一、项目简介

本项目使用 C 语言和 Linux POSIX 线程库（pthread），实现了一个多生产者、多消费者共享循环队列的任务调度系统。

多个生产者线程负责生成任务，并将任务放入共享任务队列；多个消费者线程从队列中获取任务并进行处理。

为了保证多线程环境下共享资源访问的安全性，项目使用互斥锁（Mutex）保护共享队列，并通过条件变量（Condition Variable）实现生产者与消费者之间的线程同步。

当所有生产者完成任务生产后，系统通知消费者线程退出。消费者会继续处理队列中剩余的任务，直到队列为空，确保已生产的任务能够全部被消费。

本项目主要用于学习 Linux 多线程编程、线程同步机制、循环队列设计以及多线程任务调度的基本原理。

## 二、项目功能

- 创建多个生产者线程，模拟并发任务生产。
- 创建多个消费者线程，模拟并发任务消费。
- 使用固定大小的循环队列存储任务。
- 使用互斥锁保护共享队列，避免多个线程同时修改队列导致数据竞争。
- 使用条件变量实现生产者和消费者之间的同步。
- 队列已满时，生产者等待消费者释放空间。
- 队列为空时，消费者等待生产者生产任务。
- 所有生产者完成任务生产后，通知消费者线程。
- 消费者处理完队列中的全部剩余任务后退出。
- 统计最终消费的任务数量，验证任务处理结果。

- 编程语言：C

## 四、项目参数

当前程序使用以下参数：

| 参数 | 数值 | 说明 |
|---|---:|---|
| 队列容量 | 5 | 循环队列最多存储 5 个任务 |
| 生产者线程数 | 3 | 同时运行 3 个生产者线程 |
| 消费者线程数 | 4 | 同时运行 4 个消费者线程 |
| 每个生产者生产任务数 | 20 | 每个生产者生成 20 个任务 |
| 预期生产任务总数 | 60 | 3 × 20 = 60 |
| 预期消费任务总数 | 60 | 正常运行时应消费全部任务 |

由于生产者和消费者并发执行，任务的生产顺序、消费顺序以及线程打印日志的顺序可能随每次运行而变化。
