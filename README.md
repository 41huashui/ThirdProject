# 基于 pthread 的多生产者多消费者任务队列系统

## 一、项目简介

本项目使用 C 语言和 Linux POSIX 线程库（pthread），实现多生产者、多消费者共享循环队列的任务调度系统。

生产者负责生成任务并放入队列，消费者负责从队列中取出任务。通过互斥锁和条件变量实现线程同步，保证共享队列的线程安全。

当所有生产者完成任务生产后，通知消费者处理完剩余任务并退出。

## 二、项目功能

- 创建多个生产者和消费者线程。
- 使用循环队列存储任务。
- 使用互斥锁保护共享资源。
- 使用条件变量实现线程同步。
- 队列满时，生产者等待。
- 队列空时，消费者等待。
- 所有生产者结束后，通知消费者退出。
- 统计最终消费的任务数量。

## 三、开发环境

- 编程语言：C
- 操作系统：Linux
- 编译器：GCC
- 线程库：POSIX Threads（pthread）

## 五、核心技术

### 1. 循环队列

使用数组实现固定容量的循环队列，通过 `front`、`rear` 和 `count` 管理任务，实现队列的入队和出队操作。

### 2. 互斥锁

使用 `pthread_mutex_lock()` 和 `pthread_mutex_unlock()` 保护共享队列及相关状态，避免多个线程同时访问共享资源造成数据竞争。

### 3. 条件变量

使用 `pthread_cond_wait()` 实现线程等待，使用 `pthread_cond_signal()` 通知其他线程。

- 队列满时，生产者等待。
- 队列空时，消费者等待。
- 所有生产者完成后，使用 `pthread_cond_broadcast()` 唤醒等待中的消费者。

条件变量的等待操作使用 `while` 检查条件，避免线程被唤醒后直接执行不满足条件的操作。

### 4. 线程退出管理

使用 `producer_finished` 统计已完成的生产者数量。当所有生产者完成任务后，设置 `done = 1`。

消费者只有在生产结束且队列为空时才退出，确保剩余任务得到处理。

## 六、编译与运行

编译：

    gcc main.c -o producer_consumer -pthread

运行：

    ./producer_consumer

正常运行时，最终消费任务数量应为：

    Task consum num: 60
